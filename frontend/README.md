# Frontend ObservaSRS

Aplicacao web do ObservaSRS, mantida separadamente da API e da persistencia localizadas em
`backend/`.

```text
frontend/
|-- public/
`-- src/
    |-- assets/
    |-- components/
    |   |-- layout/
    |   `-- ui/
    |-- features/
    |-- pages/
    |-- services/
    `-- types/
```
